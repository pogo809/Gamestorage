Deploy it on Cloudflare Pages

For a plain static HTML site, you can skip the build step.

  • ✓
    1. Save this file
    Keep the filename as index.html.
  • ✓
    2. Create a Pages project
    In Cloudflare, open Workers & Pages and create a Pages project. You can deploy using a Git repository or Direct Upload if available for your chosen workflow.
  • ✓
    3. Use the root directory
    For a single-file site, the folder containing index.html is the output directory. No build command is needed.
  • ✓
    4. Open the deployed URL
    Test it on both desktop and mobile. Then check the address bar for HTTPS and reload the page.
